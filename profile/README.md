1. **Name the drawing.** Give the CMS IntelliCAD CAD session a short title before you type a command.
2. **Pin the live sheets.** Keep current files on the CMS IntelliCAD DWG editor and leave unused DWG aside.
3. **Stay on the prompt.** Use the CMS IntelliCAD command workspace before you hunt for a ribbon-only path.
4. **Check the desk.** Read the CMS IntelliCAD daily desk before you archive a sheet.
5. **Close the loop.** Clear finished sheets so the next CMS IntelliCAD visit does not start with a search.

## Field Note

CMS IntelliCAD is easier to trust when the daily desk stays smaller than the folder it came from. A named session shows what is active, the command workspace shows what you will type today, and the closing note tells the next person which drawing changed.

The same loop fits a single detail, a client packet, or a PC shared by two people. Open the last CMS IntelliCAD CAD session, finish one command pass, and leave fewer loose DWG copies than you found.

A review should not have to guess which drawing belongs to the open prompt. Keep that pair together inside CMS IntelliCAD.

Other programs stay where they are. CMS IntelliCAD only holds the editor, the command workspace, and the handoff.

## One Real Pass

Pick a drawing that already has a name. Open it in CMS IntelliCAD, keep only that file on the DWG editor, and finish one command you can see.

If the pass feels crowded, the set is too wide. Drop anything that belongs to a different job and leave it out of this CMS IntelliCAD CAD session.
